# Portfolio research & design notes

## Sources actually consulted

- [Brittany Chiang](https://brittanychiang.com/): clear positioning, scannable skills, real project evidence and access to a resume.
- [Josh W. Comeau](https://www.joshwcomeau.com/): a recognisable developer personality and intentional, playful motion. The design and artwork here were built independently.
- [Nielsen Norman Group — Homepage Design: 5 Fundamental Principles](https://www.nngroup.com/articles/homepage-design-principles/): communicate who you are, show examples, and make next actions clear.
- [Motion — useReducedMotion](https://motion.dev/docs/react-use-reduced-motion): adapt animation to a visitor's motion preferences.

## Decisions for this portfolio

1. **Two audiences, clear paths.** Recruiters can read project evidence and download either resume. Prospective clients can review concrete services and prepare a project enquiry. Each path selects matching contact form copy and an email subject.
2. **Evidence before claims.** Project cards link to the repositories provided in the resumes. No client logos, testimonials or fabricated employment history are used. The Kubernetes project is described as hands-on work; AWS remains learning in progress.
3. **A distinct visual identity.** Warm paper, charcoal, muted green and burnt orange; Space Grotesk and Instrument Serif. Custom code, browser and infrastructure illustrations communicate both web development and DevOps without a stock portrait.
4. **Motion with a purpose.** Section reveals, filter transitions, subtle floating hero cards and hover feedback. Native scrolling is retained. Reduced-motion preferences disable decorative CSS animation and replace positional reveals with opacity.
5. **Straightforward contact.** Real email and phone links; the form explicitly opens the visitor's mail app. It does not claim a message has been delivered.
6. **Responsive and accessible interaction.** Mobile menu, real buttons for filters, native modal dialog with focus restoration, skip link, labelled controls and visible keyboard focus.
